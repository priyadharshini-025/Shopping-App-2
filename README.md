This is a ReactJS application that displays products and allows users to add or remove items from a shopping cart with proper routing.

Tech Stack Used
1) React JS
2) React Router
3) JavaScript
4) HTML & CSS

API Link:
 https://fakestoreapi.com/

About
 -> Products are fetched from Fake Store API
 -> Products are displayed on the Product page
 -> If Quantity changes, update prices and total prices dynamically and 10% discount is applied to the final total
